# マスコット素材

`mimi`（みみばね）、`antenna`（ふさアンテナ）、`fin`（しめり背びれ）、
`mushroom`（きのこまもり）、`cloudtail`（くもりしっぽ）の原本SVGを置く。
各フォルダの `low.svg` / `medium.svg` / `high.svg` が危険度に対応する。
SVG内のCSSには待機・タップ時のキーフレームを含む。

React NativeではCSSアニメーションを直接実行できないため、変更後は
`node scripts/generate-mascots.mjs` を実行して
`src/ui/mascot/artwork.ts` を再生成する。生成データを `Character.tsx` と
`mascot/MotionGroup.tsx` がSVGのグループ単位で描画・アニメーションする。
fill-box の相対的な回転中心は、パスの曲線極値と楕円を含む外接矩形から算出する。
外接矩形の計算は M/L/H/V/Q/C/Z のパスと translate/scale/rotate/matrix に対応し、
未対応の形状や指定が必要になった場合は、固定座標へ代替せず生成をエラーにする。
生成スクリプトは実行ディレクトリに依存しない。

アニメーションは1体につき1つのフレーム時計を共有する。各グループの周期と
キーフレーム区間ごとのCSSイージングは維持し、タップで待機動作を巻き戻さない。
本体の待機動作は7.6〜9.2秒周期で、前半64%は静止する。危険度ごとの基本動作
（低：跳ねる、中：見回す、高：よろける）に、伸び・スイング・おじぎ・2連ジャンプを
加えた5種類から毎回ランダムに選ぶ。直前と同じ動作は連続で選ばない。
追加動作も危険度が高いほど控えめにし、すべて元の姿勢へ戻ってから切り替える。
原本SVGの `<種類>-idle-*` キーフレームを本体の `idleVariants` として生成し、
アプリの `RandomIdle` が選択する（原本SVG単体のCSS再生は基本動作のみ）。
アプリの表示領域は `mascot/viewport.ts` で全種類共通の `-48 -104 416 416` にする。
待機動作とタップの重なりにも余白を確保し、ホーム・ARともSVG内部で見切れないようにする。
`tests/mascotViewport.test.mjs` で全15状態の部位ごとの動作範囲を合成し、表示領域内に収まるか確認する。
耳・背びれ・しっぽも静止区間を挟んで大きく振り、まばたきは独立して続ける。
画面外・バックグラウンド・アニメーション無効時には時計を停止してタップを破棄する。

ホーム右上の切り替えボタンは5種類を循環し、横スワイプはページを移動する。
選択中の種類はARページにも反映する。危険度の変化ではSVGを即時切り替える。
計測値がないときは薄く静止表示し、端末の「視差効果を減らす」にも対応する。

開発ビルドではホーム左上の `DEV` ボタンで、自動 → 低 → 中 → 高 → 自動の順に
マスコットの段階を確認できる。種類を変更してもプレビュー段階は維持する。
この操作はマスコットの表示だけを変更し、実測値・危険度判定・配色には影響しない。
本番ビルドではボタンを表示せず、常に実際の状態に従う。
